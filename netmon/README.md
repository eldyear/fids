# NetMon — Network Monitor

Веб-приложение для мониторинга состояния сети. Пингует хосты, фиксирует падения и восстановления, показывает всё в красивом дашборде.

## Быстрый старт (Docker)

```bash
# Сборка и запуск
docker compose up -d

# Открыть в браузере
http://localhost:5000
```

## Запуск без Docker

```bash
pip install flask
python app.py
```

## Настройки (через переменные окружения)

| Переменная      | По умолчанию | Описание                        |
|-----------------|-------------|----------------------------------|
| `PING_HOST`     | `8.8.8.8`   | Основной хост для пинга (Google) |
| `PING_HOST2`    | `1.1.1.1`   | Резервный хост (Cloudflare)      |
| `CHECK_INTERVAL`| `10`        | Интервал проверки, секунды       |
| `DB_PATH`       | `netmon.db` | Путь к SQLite базе данных        |

## Что умеет

- Пингует два хоста одновременно (если хоть один отвечает — сеть UP)
- Фиксирует все события смены статуса в SQLite
- Красный/зелёный статус с анимацией
- График задержки (последние 100 проверок)
- Timeline доступности (последние 200 проверок)
- Журнал событий с датой и временем
- Статистика: uptime %, avg latency, кол-во outages
- Данные сохраняются в volume Docker — переживают рестарт

## API

- `GET /api/status` — текущий статус
- `GET /api/events?limit=50` — журнал событий
- `GET /api/checks?limit=200` — история проверок
- `GET /api/stats` — сводная статистика

## Изменить хосты для мониторинга

Например, следить за своим сервером:

```yaml
# docker-compose.yml
environment:
  - PING_HOST=192.168.1.1
  - PING_HOST2=ya.ru
```
